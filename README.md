# Penty420.github.io

Personal website for Big Smarty (Daniel), hosted on GitHub Pages at
https://penty420.github.io.

The site is a plain static multi-page site, no build step. Open the HTML
files directly or serve the repo root with any static file server.

## Pages

- `index.html` - main landing page (English)
- `DE.html` - German version of the landing page
- `discord.html` - page for the Tech Central tech-support Discord server

## Stack

Bootstrap, jQuery, jQuery Easing, and Font Awesome, all vendored locally
under `css/`, `js/`, and `webfonts/`. Site-specific styles live in
`css/styles.css`; the shared template styling in `css/style.css`.
